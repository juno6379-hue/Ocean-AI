# 32. 관측현황 화면·동일 기준시각·실제 관측값

현행화: 2026-10-09. 검증 웹은 `http://127.0.0.1:5174/observations`, 조회 백엔드는 8010이다. 기존 canonical 서비스와 운영 worker는 유지한다.

## 화면과 조회 기준

사용자가 제공한 화면을 기준으로 상단 5개 현황 카드, 큰 지도, 시설·해역·운영상태 필터와 관측소 목록, 실제 사진을 포함한 상세정보를 배치했다. 지도와 목록에서 관측소를 선택하며 검색·페이지 이동·마지막 관측시각 정렬을 제공한다. 지도 휠 확대·축소와 일반지도·위성지도 전환을 유지한다. 시설 범례는 조위 파랑, 부이 초록, 해수유동 노랑, 과학기지 보라로 일치시킨다. 선택 범위에 해양관측소가 있으면 추가 범례를 표시한다.

관측현황의 기본 기준일은 사용자 선택인 **2026-07-09**다. 시스템의 서울 시각을 `HH:mm:ss`로 한 번 캡처하고 URL의 `as_of_day`, `as_of_time`에 고정한다. 조회하기를 누르면 새 시스템 시각으로 조회 기준을 갱신한다. 상단·지도·목록·상세·시계열은 동일 기준시각 이전의 실제 자료를 조회한다. 원천의 시각 문자열과 값을 변경하지 않으며 시간대는 승인된 것으로 추정하지 않는다.

`as_of_day`만 지정하면 그날 종료까지 포함한다. `as_of_time`을 지정하면 그 초의 정확한 시각까지 포함한다. 시간대 offset이나 해석 불가 원문 시각은 원천대로 남기되 기준일 집계에서 제외하고 제외 건수를 제공한다. 종료월이 기준일 이후이면 422다. 기준일을 생략한 기존 월 조회는 유지한다.

## 실제 값과 그래프

상세정보는 정확한 관측소·항목·수심의 원천값과 실제 관측시각을 표시한다. 수온, 염분, 풍향, 풍속 등은 존재하는 채널을 조회하며, 자료가 없는 항목을 가상 숫자로 채우지 않는다. 최근 24건의 작은 추세선과 선택 항목의 24/240건 확대 시계열을 제공한다. 시간축은 원문 달력시각의 실제 간격을 사용하며, 원천 중복과 결측을 보존한다. 풍향은 단위·주기가 확정되지 않아 점으로 표시하며 359와 0을 직선으로 연결하지 않는다. 단위·배율·기준면이 확정되지 않은 원천은 임의로 환산하지 않는다.

응답의 snapshot·원천·관측소·항목·기간·수심·기준시각을 화면 요청과 대조한다. 관측소나 기준일이 바뀌었을 때 이전 응답을 새 관측소 값으로 표시하지 않는다. 상세 데이터 링크도 기준일과 기준시각을 유지한다.

## 기준일 집계와 무결성

기존 불변 월 packet을 수정하지 않고 별도의 기준일 packet을 생성한다. 전체 파일의 grain별 행 수를 동결 카탈로그와 먼저 대조하고, 원천 파일의 SHA-256을 집계 전후 검증한다. 집계 cache는 snapshot 경로·원천·월·기준일·기준시각·계산 코드 SHA에 묶인다. packet 전체 SHA, 카탈로그 SHA와 원천 membership이 달라지면 재사용하지 않는다.

부분 월의 참고 시간격자 분모는 달력 월 시작부터 기준시각까지 계산한다. 이 값은 원천의 관측 간격을 분석한 **자료 채움 참고값**이며 예정 관측건수나 실제 수신 기록으로 산정한 수집률이 아니다. 7월 월간보고서의 전체 월 인쇄 통계를 7월 9일 수치로 재사용하지 않는다.

부모 에이전트는 집계 엔진과 별도로 PyArrow로 실제 7월 파일 143개를 읽어 다음 범위를 대조했다.

| 기준 | 결과 |
|---|---|
| 원천·기간 | GD_OBS_ST_MONTHLY, 2026-07-01부터 2026-07-09 15:33:17까지 |
| 실제 자료 보유 관측소 | 61개 |
| 기준시각 이전 원천 행 | 7,122,070행 |
| 마지막 실제 원문 시각 | 2026-07-09 15:33:00 |
| 진도 DT_0028 | 수온 21.41, 염분 31.45, 조위 VEGA 221, 풍속 4.3 |
| 네 항목의 실제 시각 | 모두 2026-07-09 15:33:00 |

위 숫자는 해당 고정 검증 시각의 원천값이다. 화면에서 다른 시스템 시각으로 조회하면 그 시각에 맞춰 달라진다. 원천 행은 중복을 포함하며 고유 관측건수라고 부르지 않는다.

추가로 **2026-07-09 15:41:20** 기준의 수온·염분·풍향·풍속·조위 각각 최근 240행, 총 1,200행을 PyArrow로 독립 대조했다. 원문값·시각·파일·행번호·순서·수치 해석과 `has_more`가 API와 일치했다. 마지막 실제 시각은 모두 15:41:00이며 진도의 원천값은 수온 21.38, 염분 31.45, 풍향 180, 풍속 2.1, 조위 VEGA 228이다. 해당 시각의 전체 집계는 61개소·7,126,689행이다.

## 실제 관측소 사진

사진 API는 국립해양조사원 공개 상세 응답의 관측소 코드와 요청 코드를 대조한다. 실제 이미지의 magic bytes로 형식을 확인하고, 외부 상세 URL과 응답 크기를 제한한다. 공개 사진은 촬영일이 확인되지 않았으므로 **7월 9일 촬영 사진이라는 주장을 하지 않는다**. 사진 조회 중·미공개·실패를 구분하며 임의 시설 사진으로 대체하지 않는다.

7월 9일 GD 실제 보유 관측소 61개를 전수 확인한 결과 공식 사진은 58개에 연결됐고, DT_0064·DT_0903은 공개 사진이 없으며 DT_0095는 공식 응답 오류가 발생했다. 외부 사이트 상태에 따라 후속 조회 결과가 달라질 수 있다.

보존된 기존 `webMTR2/stImg`, `stImg2`, `stImg3`에는 각각 67·59·61개, 합계 187개 이미지 파일이 있다. 판본 간 중복을 고려하면 파일명 76종·이미지 SHA 181종이다. 현재 61개 관측소 중 39개는 보존된 JSP의 `DT_TS_ID → WEB_MTR_INFO.OLD_ID → OBS_POST_ID` 규칙과 공식 현재 코드 메타데이터에 연결되는 후보가 있다. 파일 번호를 현재 코드로 추측하거나 판본별 이미지를 서로 다른 관측소로 세지 않는다. 원본 사진과 후보 목록은 로컬에 보존한다.

## 운영상태·수집률의 경계

현황 카드와 목록에 요청된 운영상태·수집률 항목을 배치했다. 그러나 기준일 운영·장애 기록과 예정 관측건수·수신 이력의 근거가 확인되지 않아 정상·주의·이상과 수집률은 숫자를 만들지 않고 확인 필요로 표시한다.

읽기 전용 DB 확인에서 `quality_collection_report`, `daily_inspection_report`, `operation_log`는 모두 0건이었다. `station_metadata`의 현재 상태 문자열은 7월 9일의 유효기간·판정 근거가 없어 과거 운영상태로 사용하지 않는다. 전체 자료 보유 관측소 61개와 지도 좌표가 있는 59개도 구분한다. 장비 정상이나 QC 승인을 원천값 존재만으로 확정하지 않는다.

## API와 검증 기록

| 경로 | 추가된 읽기 전용 기능 |
|---|---|
| `/api/lake/summary` | 선택 원천·기간·시설·해역의 기준일 집계 |
| `/api/lake/metric-completion` | 같은 기준시각의 원천 진단·참고 격자 |
| `/api/lake/stations/{station}` | 기준시각 이전 실제 항목·수심·월 목록 |
| `/api/lake/series` | 정확한 항목·수심과 `tail=true`의 기준시각 시계열 |
| `/api/stations/{station_id}/photograph` | 코드가 일치하는 실제 공식 사진 |

앞의 네 경로는 선택 query `as_of_day`, `as_of_time`을 받는다. 과거 정산 원천 `HISTORICAL_RECONCILED`는 아직 기준일 집계를 지원하지 않고 422로 알린다. 쓰기·담당 승인·모델 등록 경로를 우회하지 않는다.

실행 서버의 최신 OpenAPI는 사진 경로 추가 후 **155 경로·164 HTTP operation**이다.

세 에이전트가 UI·그래프, 실제 데이터 정합성, 사진 매칭을 각각 검토하고 서로의 계약을 대조했다. 부모의 최종 시험·브라우저 검증과 공개 가능한 증거 SHA는 [검증 기록](32_OBSERVATION_WORKSPACE_ASOF.json)에 기록한다. 원문·Parquet·사진·실제 응답과 DB 연결 정보는 Git에 포함하지 않는다.

최종 부모 검증은 backend **788 passed / 1 skipped**, frontend **45 passed**, TypeScript·Vite production build 통과다. 실제 브라우저 11개 확인에서 5항목 값과 240건 그래프, 풍향 개별 점, 24건 전환, 키보드 기록 선택·원천 표, 관측소·사진 전환, 상세 페이지 기준 유지, 목록 검색·페이지 범위, 지도 휠 확대, 모바일 400px 폭, 데스크톱 그래프, 서해 필터 집계를 확인했다. 판본과 의미를 승인하거나 운영 모델을 배포한 결과가 아니다.
