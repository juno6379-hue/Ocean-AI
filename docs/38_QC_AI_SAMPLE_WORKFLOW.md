# 38. QC·AI 인사이트 샘플 실행

기준: 2026-10-09. 사용자가 별도 QC 샘플을 운영 QC 화면에서도 선택하도록 요청했고, 첨부한 AI 인사이트 디자인에 합성 시나리오·분석·검토·보고서를 연결하도록 요청했다. 이전 별도 샘플 구현과 시험은 [37](37_QC_SAMPLE_VALIDATION_MODE.md)에 보존한다.

## QC 모드 연결

운영 QC의 자료 경로에서 ‘샘플 · 가상 시험자료’를 선택하면 `/qc?source=SAMPLE`로 이동한다. 이 분기는 운영 QC 컴포넌트를 마운트하지 않고 기존 샘플 전용 API를 사용한다. 화면은 같은 masthead·품질 현황 제목·6개 KPI·분포/추이/Rule/행렬/사례/검토 배치를 제공한다. 실제 원천·검토 원장을 샘플로 적재하지 않는다.

샘플 시간창은 2026-07-09 14:40~15:40 +09:00, 조회 기준은 15:41:20이다. 전체 가상 4사례 범위로 고정하며 대표 사례 4건과 예정 슬롯 244개를 구분한다. 시나리오 선택은 상세 검토를 열고 전체 집계 분모를 바꾸지 않는다. 정상·지연·결측·Spike 계산·검토 상태 기계는 [37](37_QC_SAMPLE_VALIDATION_MODE.md)을 재사용한다. 기존 `/qc/sample`도 유지한다.

실제 운영 자료로 전환하면 샘플 요청을 중단하고 샘플 상태를 제거한다. URL의 샘플 후보·기간·필터가 실제 자료 조회에 남지 않는다. QC↔AI 메뉴는 명시적 샘플 모드를 유지하고, 관측현황·장비·실제 모델 등 다른 메뉴는 샘플 query를 전달하지 않는다. 샘플에서는 공통 실제 계정·운영 단계 패널과 실제 RAG chatbot을 마운트하지 않는다.

## AI 인사이트 구현 기준

`/ai-insights?source=SAMPLE`은 별도 합성 분석을 표시하고 기본 실제 자료 화면은 유지한다. 첨부 이미지의 구성은 5개 KPI, 이상 탐지 추이, 예측값/관측값 비교, 설명, 위험 지도와 가상 관측소 순위, 선택 사례 상세, 보고서 목록과 감지→설명→검토→보고 단계다. 이미지에 쓰인 93개소·36건·94.8%·OceanNet 등의 숫자나 모델 이름을 실행 결과로 복사하지 않는다.

합성 시나리오는 정상, 고수온·인접 센서 동반 상승, 센서 Spike, 염분 Drift다. 가상 관측소 ID와 명시된 시험 좌표·단위를 사용한다. 기준시각은 QC와 같은 2026-07-09 15:41:20 +09:00이고 미래 값을 그래프나 특징·평가에 넣지 않는다. 실제 관측소 코드나 물리 센서 승인으로 해석하지 않는다.

예측은 persistence와 Ridge 후보를 시간 순서의 TRAIN/VALIDATION/TEST로 비교한다. 후보 선정은 validation, test는 최종 평가에만 사용한다. 이상·Drift는 기존 fitted anomaly 엔진을 합성 입력에 실행하고 주입 정답과 평가 범위·미평가 건수를 표시한다. 단위가 다른 수온과 염분의 오차를 하나의 온도 오차로 합산하지 않는다. 확률로 검증되지 않은 값은 신뢰확률이나 정확도로 표시하지 않는다. 정의한 근거 점수와 실제 계산한 평가 지표를 구분한다.

QC·AI 각각의 세션·token·메모리 저장소는 분리한다. AI sample은 `/api/ai-insights-sample`만 호출하고 실제 운영 Authorization/cookie를 전달하지 않는다. 기본 `AI_INSIGHTS_SAMPLE_ENABLED=false`이며 development/test/local에서 명시 활성화한다. source=SAMPLE·approved=false·운영 원장 쓰기 0을 유지한다. 샘플에서 학습한 개발용 기준선은 실제 운영 registry/serving 모델이 아니다.

검토는 PENDING에서 멈추고 승인 후에도 명시 재개 전까지 멈춘다. 재개는 샘플 보고서만 생성한다. 보류·반려·추천 SHA·revision·멱등성·다른 세션 차단·초기화를 검증한다. 재학습 후보는 격리된 제안이며 실제 학습 큐 등록이나 운영 모델 배포를 수행하지 않는다.

## 합성 데이터·후보 학습·평가 계약

각 가상 관측소의 주 센서·독립 비교 센서는 2026-06-01 00:00부터 2026-07-09 15:00까지 928개 시간 슬롯을 생성한다. 동일 합성 정의·고정 seed를 사용하며 원천 파일을 읽지 않는다. 분할은 TRAIN `[06-01,06-21)` 480행, VALIDATION `[06-21,06-28)` 168행, TEST `[06-28,07-09 16:00)` 280행이다. 16:00은 다음 시간 격자의 배타적 경계이며 실제 관측 생성·가용시각의 마지막은 15:00이고 effective cutoff는 15:41:20이다. 다음 시간 예측은 16:00 대상의 미래 **예측**으로만 표기하며 관측값에 합치지 않는다.

Ridge alpha 0.01/0.1/1.0을 TRAIN만으로 전처리·학습하고 직전값 persistence와 VALIDATION MAE를 비교한다. 각 분할 첫 3행을 제외하여 예측 비교 쌍은 477/165/277개다. 테스트 값으로 후보를 다시 선정하거나 재학습하지 않는다. 네 사례에서 Ridge가 선정되었고 fitted Ridge 후보는 12개다. SPIKE·DRIFT는 각 사례의 TRAIN robust 통계와 VALIDATION calibration으로 fit한 8개 mode다. TEST 시작의 7행은 선행 창 부족으로 미평가이고, 사례별 공통 평가 273행·합계 1,092행 / 총 TEST 1,120행이다.

| 시나리오 | 주입 정답·판단 | TP / FP / FN / TN | 센서 편차 FPR | Ridge TEST MAE / RMSE | Persistence TEST MAE / RMSE |
|---|---|---|---|---|---|
| 정상 변동 | 센서 편차 주입 없음. 현재 표본은 기준선 이내이며 기간 전체에 오탐 존재 | 0 / 29 / 0 / 244 | 10.62% | 0.03334 / 0.04023 °C | 0.15399 / 0.17223 °C |
| 고수온·인접 센서 | 마지막 36시간에 최대 +6°C ramp를 주·비교 센서에 함께 주입. 환경 변화 후보이며 센서 고장 정답이 아님 | 0 / 15 / 0 / 258 | 5.49% | 0.05552 / 0.10400 °C | 0.16259 / 0.18705 °C |
| 센서 Spike | TEST index 80/160/240/276에 +5°C. 다음 정상 복귀까지 transition 정답 8행 | 8 / 7 / 0 / 258 | 2.64% | 0.26721 / 1.16773 °C | 0.29295 / 0.86578 °C |
| 염분 Drift | TEST index 200 이후 주 센서에 시간당 +0.035 psu, 비교 센서 변화 없음. 정답 79행 | 78 / 9 / 1 / 185 | 4.64% | 0.06748 / 0.11325 psu | 0.05205 / 0.06073 psu |

TP/FP/FN/TN은 두 mode가 모두 평가된 행에서 하나 이상 ANOMALY이면 센서 편차 후보로 판단한 결과다. FPR 분모는 주입 센서 편차가 없는 평가 행이다. 환경 상승은 센서 편차 정답으로 계산하지 않는다. 표의 오탐·미탐과 TEST에서 persistence가 더 나은 지표를 그대로 보존한다. 예측 오차·calibration 순위는 운영 품질 수용이나 검증된 고장 확률이 아니다.

첨부 디자인의 ‘위험 지도’는 네 가상 시험 좌표와 후보 판정을 표시한다. 인접 센서 동반 상승 비교는 구현했지만 실제 관측망으로 학습한 spatio-temporal 모델은 없다. LSTM/XGBoost/Transformer 등의 학습·배포 완료를 주장하지 않는다. 설명과 보고서 문장은 계산 결과를 채운 template이며 외부 LLM/RAG를 호출하지 않는다.

## 최종 검증과 사용 방법

UI·계산·독립 검토 에이전트의 작업을 통합했고 루트가 최종 검증했다. AI backend 집중 25개와 독립 39개, 합계 64개는 전체 backend **1,106 passed / 1 skipped / 18 warnings, 399.81초**에 포함한다. 집중 검사와 전체 회귀 수를 합산하지 않는다. skip은 기존 Windows symlink 권한 시험이다. 동결 backend 279개 소스는 시험 전후 동일했다.

Frontend 전체 **146/146 passed**, production build PASS, lint 오류 0·기존 경고 12개·신규 QC/AI 경고 0개다. QC workspace 독립 실제 React DOM 9개와 AI 응답·실제 DOM 경계 검사는 전체 회귀에 포함한다. 동결 frontend 107개 파일이 검사 전후 동일했고 기존 build bundle 크기 경고는 유지된다.

루트는 실행 중인 8010 서버에서 **57개 HTTP·독립 수치 재계산 확인**을 통과했다. 별도 생성식으로 4×928행·TRAIN 전처리/Ridge fit·validation 후보 선정·TEST 예측/MAE/RMSE와 4×280행의 평가·TP/FP/FN/TN·선택 값/시각/점수·미래 예측 분리를 대조했다. 세션·QC/AI token 교차·실제 Bearer/cookie 혼용·strict 입력·CAS·멱등·중지/재개·보고서 byte SHA·초기화를 실제 HTTP로 확인했다.

실제 브라우저 **AI 1280×720 / QC 890×836에서 29개 확인**을 통과했다. 네 시나리오·지도/순위 선택·값/그래프/단위·평가·확대·검토·보류/반려·승인 시 중지·명시 재개·보고서 다운로드·초기화·실제 모드 복귀를 검증했다. 두 화면 모두 수평 넘침이 없고 최종 동결 이후 AI 화면 console 오류도 없다. 이 기록은 실제 검증한 브라우저 크기의 결과이며 데스크톱 전 해상도 인증을 뜻하지 않는다.

검토 전후 운영 PostgreSQL **13개 표의 행 수와 전체 행 내용 fingerprint가 동일**했고 durable worker queue의 행 수·내용 hash도 같았다. raw 13,621행·standard 4,074행을 유지하며 source/QC/승인/dataset/model/workflow/재학습 원장과 queue는 0건이다. 기존 canonical 8000/5173·문서 8001·시험 모델 8011을 보존하고 샘플 flag는 검토용 8010에서만 활성화했다. 샘플이 운영 schema·원천·승인·실제 모델을 바꾸지 않았음을 확인했다.

1. 시험 웹의 QC 자료 경로에서 **샘플 · 가상 시험자료**를 선택하거나 `/qc?source=SAMPLE`에 접속한다.
2. QC의 **AI 샘플 인사이트** 또는 `/ai-insights?source=SAMPLE`에서 네 합성 시나리오를 선택한다. 지도·순위·보고서 목록의 선택도 상세와 같은 시나리오로 연결된다.
3. 같은 시간·행의 관측/예측/독립 센서·선택 표본·모델 후보·고정 분할·오탐/미탐·근거 SHA를 확인한다.
4. 의견을 입력하고 **샘플 승인**한다. APPROVED도 후속 단계는 멈춘다. 다른 의견과 **샘플 보고서 단계 재개**를 실행해야 READY가 된다.
5. **샘플 보고서 보기 → 샘플 Markdown 다운로드**로 계산 지표·검토 이력·격리 표시가 있는 파일을 확인한다. 실제 발송은 없다.
6. **샘플 초기화**는 현재 가상 세션의 새 generation으로 되돌린다. 자료 경로를 운영 자료로 바꾸면 샘플 요청·상태·query가 남지 않는다.

현재 완료 범위는 **첨부 AI 인사이트 구성과 합성 학습·평가·검토·보고서 시나리오의 실행**이다. 정량 설명가능성·고장 확률·불확실성과 실제 운영 모델/승인은 별도 미완료다. 실제 준비 상태는 [운영 경계 36](36_QC_OPERATIONAL_DASHBOARD_EXECUTION.md), 이전 별도 QC 샘플 증빙은 [37](37_QC_SAMPLE_VALIDATION_MODE.md)에 보존한다. 소스·검증·브라우저 증빙 SHA는 [기계 판독 기록](38_QC_AI_SAMPLE_WORKFLOW.json)에 남긴다.
