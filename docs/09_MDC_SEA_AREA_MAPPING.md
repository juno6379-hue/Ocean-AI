# MDC 관측소 해역 및 지도 위치 매핑

작성일: 2026-09-16

## 확인된 원인

`WEB_STATION.DO_NM`은 해역명이 아니라 소속 도·시 행정구역이다. 이 값을 해역 필터와 지도 팝업에 사용하면 전남·경상북도 같은 행정구역이 해역으로 표시된다. 좌표가 없는 관측소를 지도 중심점에 대체 표시하는 것도 위치 오류를 만든다.

## 적용한 기준

`sync_metadata()`가 `OBS_LAT`, `OBS_LON`으로 `StationMetadata.sea_area`를 계산한다.

| 조건 | 저장 해역 |
|---|---|
| 위도 ≤ 34.0, 경도 ≥ 125.0 | 제주해역 |
| 경도 ≥ 128.0 | 동해 |
| 경도 ≤ 126.5 | 서해 |
| 그 외 유효 좌표 | 남해 |
| 좌표 누락·범위 오류 | 미상 |

이 기준은 지도와 해역 필터에서 동일하게 사용된다. 좌표가 없는 관측소는 표와 상세에는 남기지만 지도 마커에서는 제외한다.

|---|---:|

해양과학기지 코드는 좌표에 따라 이어도 `IE_0060`은 제주해역, 신안가거초 `IE_0061`과 옹진소청초 `IE_0062`는 서해로 표시된다.

## 화면 반영

- 관측 현황 지도: MDC 좌표와 계산된 `sea_area`를 사용하고 좌표 누락 마커를 생성하지 않는다.
- 통합 대시보드 지도: 동일 좌표와 해역을 팝업에 표시한다.
- 관측 현황·상세 화면: 해역 필터와 해역 정보가 행정구역 값과 섞이지 않는다.
