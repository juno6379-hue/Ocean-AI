# 28. 미산정 지표 보완과 산정 경계

기준일: 2026-10-09. 관측 기본 기준월은 2026년 7월이다. 아래 7월 집계는 10/8 검증 기록이며, 보유 전 기간의 재산정과 관측현황 화면 변경은 [31. 관측현황 재산정](31_OBSERVATION_METRIC_RECALCULATION.md)을 따른다. 실제 Parquet 전수 진단과 월간해양정보의 인쇄 수치를 조회 API·Dashboard·관측 현황·QC·AI Insights에 연결했다. 모델·장비·서비스는 각자의 평가 대상·원장·요청 기록 범위를 사용한다. 구현 완료와 운영 승인 완료를 구분한다.

## 실제 계산한 값

146개 Parquet를 다시 SHA256·footer 행 수로 검증했다. 4개 원천의 보유 채널 1,832개와 카탈로그만 있는 273개, 총 2,105개 채널·월을 정확한 원천/관측소/항목/문자형 수심 grain으로 집계했다. 기존 GDST의 고유 관측시각 NULL 610개를 실제 파일에서 산출해 보완했다. 부모는 별도 직접 파일 읽기로 안정·불안정 위상 사례 7개를 확인했고 두 에이전트가 서로의 원장을 교차검증했다.

아래 참고 보유율의 분모는 실제 시각의 **유일 최빈 양의 간격**과 **완전히 일치하는 위상**으로 구성한 전체 7월의 슬롯이다. 동일 grain 내 같은 관측시각은 한 번만 센다. 첫·마지막 보유 시각으로 월 분모를 줄이거나 시각을 반올림하지 않는다. 전체 월을 기준으로 산정 가능한 1,804채널만 합산하며, 위상 불안정 28개와 보유 0행 273개는 제외 사유와 NULL을 보존한다. 제외 채널을 정상·실패·실제 미수집으로 판정하지 않는다. 서로 겹치는 원천의 비율은 합치지 않는다.

결측 표현은 NULL 또는 trim 후 빈 문자열이며 숫자 sentinel을 임의 제거하지 않는다. 수치 표현율은 finite DOUBLE 해석 가능 행의 비율이다. 시각 해석불가율, 정확 시각 중복 행, 필드별 QC 원문 분포도 별도로 제공한다. QC 표기율은 SQL `qc_raw` 또는 부이 `QC_FLAG`의 비공백 표기 행/원천 보유 행이다. 보조 QC FLAG는 원문 분포로 보존하며 `OK`, `G ` 등을 승인된 정상·BAD로 바꾸지 않는다. GR에는 QC 필드가 없으므로 0% 대신 필드 부재를 표시한다.

7월 해양관측소 보유 목록은 교본초·왕돌초 2개다. 복사초 등 보유 0행 카탈로그 코드는 `catalog_only_station_codes`에 따로 보존하며 현재 보유 관측소로 세지 않는다. 운영·폐지·고장 판정과는 별개다.

## 보고서 인쇄값 참조

보고서 시설별 정상자료율 100행을 원문·표·페이지·PDF SHA와 함께 보존했다. 집계 18행과 HF 관측해역 16개 숫자는 별도 자료이며 HF 44개 개별 관측소의 정상률로 연결하지 않는다. 셀 ID는 시설·표·항목군별로 유일하며 인쇄된 평균 셀을 다시 평균에 넣지 않는다. 실제 보유 771개 채널에 참조가 있고 고유 참조 셀은 333개다. 카탈로그 0행 채널의 수치 참조는 게시 통계에서 제외했다.

화면의 ‘보고서 정상자료율 평균 (참조)’는 **현재 원천/필터에 해당하는 고유 시설·항목군 인쇄 셀을 한 번씩 산술평균**한 값이다. 보고서 자체의 평균 산식·원천 행 가중치·개별 수심/센서 정상률을 재현한 값이 아니다. 예컨대 원문의 집계 91.9와 표시 항목 8개의 단순 평균 91.8은 다르므로 원문 평균을 임의 재계산하지 않는다. 바람·파랑·해수유동 항목군과 개별 원천 변수의 대응은 미승인 참조다.

수집률·오류율·결측률은 보고서에 정확한 시설·항목별 숫자가 기재되지 않은 경우 NULL과 이유를 보존한다. `100 − 정상자료율`로 오류율·결측률을 만들지 않는다. 원문 2차 QC와 원시 QC 표기는 서로 다른 근거다.

## API와 화면 범위

`GET /api/lake/metric-completion`은 source, from_month, to_month, network, sea, station, item을 받는다. 기본 월은 2026-07이고 Dashboard 상단 KPI는 원천/기간/관측망/해역 기준이다. 관측소·항목의 국소 표 필터와 상단 전체 KPI를 섞지 않는다. QC·Insights는 선택한 exact scope로 조회한다. Observations 표는 관측소별 참고 시간격자 보유율을 제공한다.

선택 기간의 월별 불변 원천 진단을 합산한다. 현재 카탈로그의 보유 건수는 있으나 해당 월의 원천 재검사가 없으면 `PARTIAL_CATALOG_COUNTS`와 완료/미완료 월 목록을 반환하고, 계산하지 않은 통계를 0으로 바꾸지 않는다. 보유 자료가 없는 범위는 `EMPTY_SCOPE`이며 비율은 0%가 아니다. 7월 보고서 인쇄값은 7월의 동일 원천·관측소·항목·타입 보존 수심에만 연결한다. checksum·기준월·원천 변경은409, 손상된 기록은503으로 막는다. 요청 취소와 같은 snapshot 검증으로 화면의 이전 응답이 새 필터를 덮지 않게 한다.

## 서비스·장비·모델의 남은 입력

서비스의 요청 오류율과 평균 지연은 현재 API 프로세스의 실제 처리 응답 기록에서 계산한다. HTTP400 이상을 오류로 정의하며 기록 구간·처리 건수·오류 건수·상태 코드 분포·재시작 시각을 함께 제공한다. 조회 자체는 처리 후 다음 조회에 반영된다. 최대50,000개만 보유하고 삭제된 경계보다 이전 구간의 완전성을 주장하지 않는다. 과거·재시작 전 이력, 하루 가동률, 동시 접속자는 별도 입력이 필요하다. 관측 7월과 서비스의 현재 실행 구간을 구분한다. [요청 집계](../ocean-ai-platform/backend/app/services/http_request_metrics.py), [서비스 조회](../ocean-ai-platform/backend/app/services/service_observability.py).

실제 수집률에는 주기·센서 유효기간·시간대·예정 건수가, 승인 정상/BAD 비율에는 QC 판본·시행기간·코드 의미·판정 분모가 필요하다. 장비 가동률과 정비 완료율에는 heartbeat/운영기간 및 정비 대상·완료 원장이 필요하다. RMSE/F1에는 학습·고정 test pair·단위·task/label 정의가 필요하다. 현재 모델0개에서는 ‘평가대상 없음’으로 표시한다. 없는 근거를 가동률100%·오류0%·정비완료·AI 성능으로 채우지 않았다. 실제 계정 설정은 기존 사용자 지시대로 실제 운영 시점에 진행한다.
