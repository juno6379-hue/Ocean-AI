# 39. 샘플 데이터 기반 QC·AI 메뉴 실행

기준일: 2026-10-10. 사용자가 샘플 데이터를 AI 인사이트와 앞선 품질 QC의 구현 화면에 반영하도록 요청했다. 이번 단계는 표준 메뉴에서 샘플 계산·검토 화면을 바로 사용할 수 있도록 진입 규칙을 변경한다. 합성 데이터와 엔진의 학습·평가·검토 계약은 [38](38_QC_AI_SAMPLE_WORKFLOW.md)에 보존한다.

## 구현 범위와 역할

| 담당 | 작업 | 완료 판정 |
|---|---|---|
| UI 에이전트 | 신규 QC·AI 메뉴 진입, 자료 경로 선택, 공통 메뉴의 선택 유지 | 첫 렌더부터 샘플 사용·운영 전환 및 재조회 보존 |
| 독립 검토 에이전트 | 실제 React DOM에서 진입·전환·이동·필터·격리 회귀 | 네 시나리오와 검토 기능 유지·운영 선택 재샘플화 차단 |
| 데이터·API 검토 에이전트 | 기존 QC·AI 엔진의 API 계산·중지/재개·격리 확인 | 별도 신규 세션 시험·운영 쓰기 0·backend 변경 0 |
| 루트 | 전체 frontend 시험/build·실제 브라우저·운영 DB/큐 전후 대조·문서·Git | 시험 소스/커밋의 해시 일치와 원격 반영 확인 |

## 자료 선택 기준

문맥 없는 `/qc`, `/copilot`, `/ai-insights`의 신규 진입은 명확하게 표시된 SAMPLE 화면을 열고 `source=SAMPLE`로 정규화한다. 첫 순간에 운영 빈 화면이나 운영 계정 패널을 실행하지 않는다. 샘플 선택에서는 운영 원천·관측소·기간·기준시각 문맥을 제거한다.

운영 자료를 선택하면 `data_mode=LIVE`를 명시하여 실제 조회를 계속 유지한다. 이미 원천·관측소·기간·기준시각을 지정한 기존 주소도 실제 조회 문맥을 보존한다. 운영으로 선택한 뒤 새로고침하거나 QC↔AI 메뉴를 이동해도 다시 샘플로 바뀌지 않는다. 다른 업무 메뉴에 SAMPLE 문맥을 전달하지 않는다.

샘플은 기준시각 2026-07-09 15:41:20 +09:00을 유지한다. QC의 정상·수신 지연·결측·Spike는 예정 분 슬롯 244개를 기존 Rule 엔진으로 계산한다. AI의 정상·고수온 동반 상승·Spike·염분 Drift는 별도의 합성 시간 자료 4×928행으로 개발 예측 후보와 fitted 통계 탐지를 계산한다. 두 자료는 목적과 시간 간격이 다른 독립 데이터셋이며, 같은 실관측 행으로 합치지 않는다.

검토 대기와 승인 후 명시 재개 전에는 후속 단계가 중지된다. QC 재개는 합성 후속 초안, AI 재개는 합성 검토 보고서를 생성한다. 가상 담당자 처리는 실제 계정 승인·Final QC·registry·serving·학습 큐의 완료로 기록하지 않는다. 실제 운영 모델 수는 0이며 검증되지 않은 고장 확률·정량 설명가능성 점수는 제공하지 않는다.

## 최종 검증

UI·독립 검토·데이터/API 검토를 통합하고 루트가 동결 소스로 최종 검증했다. Frontend 전체 **155/155 통과**, production build PASS, lint 오류 0·기존 경고 12·신규 경고 0이다. 검사 전후 109개 frontend 파일이 동일했다. Backend 279개 소스는 [38](38_QC_AI_SAMPLE_WORKFLOW.md)의 전체 1,106 passed / 1 skipped 시험 소스와 동일하며, 이번 단계에서 backend 시험을 재실행한 수로 보고하지 않는다.

실제 브라우저 **29개 확인**을 통과했다. 기본 QC·AI 진입, 기존 보존 원천의 기간·관측소·시각 유지, 운영 선택 후 새로고침 및 QC↔AI 이동, 샘플 우선 정규화, 실제 계산 KPI·그래프·사례 상세와 승인 중지/재개를 확인했다. 실제 검증한 화면 크기는 기계 판독 기록의 viewports에 남긴다. 데이터/API 검토 에이전트는 신규 자체 가상 세션으로 실행 서버 HTTP 63회·78개 확인을 통과했고 token 교차·보고서 byte SHA·중지/재개·초기화·운영 조회 투영 불변을 대조했다.

전후 운영 PostgreSQL 13개 표의 전체 행 fingerprint와 durable worker queue의 행 수·내용 SHA가 같았다. raw 13,621행·standard 4,074행·실제 모델 0건과 학습 큐 0건을 유지한다. 이전 37·38단계 문서와 JSON 영수증은 수정하지 않았다. [소스·검증 기록](39_SAMPLE_DATA_WORKSPACE_ENTRY.json)에 SHA와 완료 범위를 기록한다.

## 실행 방법

1. 표준 메뉴의 **품질 현황(QC)** 또는 `/qc`를 열면 샘플 네 사례를 바로 계산해 보여 준다. 행렬 또는 사례 목록에서 근거와 그래프를 확인하고 의견·샘플 승인·후속 단계 재개를 시험한다.
2. **AI 분석 인사이트** 또는 `/ai-insights`에서 네 합성 시나리오의 개발 모델·예측·탐지·평가를 확인한다. 지도·순위·보고서 사례 선택은 상세와 동기화된다.
3. **자료 경로**에서 운영 자료를 선택하면 실제 조회로 전환한다. 새로고침·메뉴 이동에도 선택이 유지되며 샘플 판정을 운영 원장에 적재하지 않는다.
4. 두 화면의 **샘플 초기화**는 현재 가상 세션만 초기화한다. 운영 원천·Final QC·실제 학습·배포에는 영향을 주지 않는다.

현재 완료 범위는 **표준 QC·AI 메뉴에서 샘플 데이터를 사용해 기존 계산·검토 기능을 실행하는 흐름**이다. 실제 담당자 승인, 실제 운영 모델 등록·배포 및 검증되지 않은 정량 설명가능성·고장 확률은 완료 범위에 포함하지 않는다.
