# 31. 관측현황 UX와 보유 전 기간의 원천 지표 재산정

기준일: 2026-10-09. 현황의 기본 관측월은 **2026년 7월**이다. 관측소 월별 원천 43개월과 추가 원천 3종의 각 33개월을 실제 Parquet에서 다시 계산했다. 시각·값·QC 코드의 원문 진단과 실제 운영 판정을 구분한다.

## 화면 변경

관측현황 상단의 ‘실측 원천 보유 현황 · QC 승인 전’, 원천 전체 관측시각·시간대·43개월 설명, 검증본·legacy HOLD 안내 블록을 제거했다. 지표 산정 근거·QC 원문 분포와 7월 보고서 대조는 접어서 필요할 때 확인한다.

사용자가 확인할 순서는 **해역·관측소 선택 → 관측항목 확인 → 최근 실측값 → 기간별 자료 공백 → 상세 QC·원천 근거**다. 해역·관측망·관측소·기간 선택을 지도 위에 배치하고, 데스크톱 지도를 본문 2/3 너비·560px 높이로 넓혔다. 지도 점·선택 메뉴·목록 버튼이 같은 관측소 선택 상태를 사용한다. 선택한 관측소로 이동하고 주황색으로 강조하며 ‘전체 위치’로 현재 해역 범위를 다시 볼 수 있다. 좌표가 없는 관측소도 선택 메뉴와 목록에서 확인할 수 있다.

지도 위 마우스 휠은 확대·축소에 사용한다. 시작월·종료월은 ‘기간 적용’으로 함께 반영하며, 적용 전에는 현재 결과의 기간을 표시한다. 월별 자료 유무 버튼을 누르면 해당 한 달을 조회하고 ‘7월 기준으로’로 현황 기준월에 복귀한다.

상단 카드는 자료 있는 관측소·관측항목·자료 있는 월·참고 자료 채움을 표시한다. 선택 관측소에는 항목·수심 선택, 원문 관측시각 순의 최근 24건과 원문 QC, 채널별 월별 자료 유무를 제공한다. 단위 적용 전 원천값이며 정상/이상 판정으로 표시하지 않는다. 단순 ‘월별 원천 행 수’ 차트와 항목 수 순위 막대, 미연결 수신 알림 영역을 제거했다. 월별 자료 유무는 실제 보유 근거로 표시하며 자료가 없는 월을 운영 중단으로 바꾸지 않는다.

원천 행 수·결측표현율·수치 표현율·원천 QC 표기율과 산정 조건은 하단 ‘자료 출처·산정 근거’에 모았다. 마지막 원문 관측시각은 목록에, 수신−관측 시계차의 평균·P95 또는 실제 필드 부재는 선택 관측소의 ‘기간’ 탭에 표시한다. 반복 업무·기준월 안내는 관측현황 본문과 통합해 지도 공간을 확보했다.

## 실제 원천 재계산 범위

| 원천 | 보유 기간 | 재계산 월 수 | 보유 원천 행 수 |
|---|---|---:|---:|
| `GD_OBS_ST_MONTHLY` | 2023-01 ~ 2026-07 | 43 | 1,017,630,666 |
| `GD_OBS_BU` | 2024-01 ~ 2026-09 | 33 | 96,431,020 |
| `GD_OBS_VBU` | 2024-01 ~ 2026-09 | 33 | 19,527,381 |
| `GR_OBS_ST` | 2024-01 ~ 2026-09 | 33 | 791,691,641 |

합계 142개 원천·월, 66,190개 원천·관측소·항목·타입 보존 수심·월, 6,248개 파일을 재검사했다. 1,925,280,708행은 겹치는 원천별 집계를 합한 수이며 고유 관측 수가 아니다. 9월은 보유분만의 진단이며 월 전체 수집 완료를 뜻하지 않는다. 서로 다른 원천의 수집률·정상률을 합산하지 않는다.

각 파일의 현재 SHA256·footer·schema와 계산 전후 SHA, frozen catalog·source-assets SHA, 실행 시 로드한 계산 코드 SHA를 기록한다. 월별 파일 목록·원천·typed grain·행 수를 정산하고 불변 `packet-<sha>.json`과 원자적 게시 포인터를 저장한다. 기존 7월 검증 패킷은 보존했다. 삭제한 `D:\share` 대신 보존된 data lake의 Parquet를 사용하며 원본 CSV의 현재 보존을 새로 주장하지 않는다.

## 산식과 원문 의미

시간격자는 동일 원천·월·관측소·항목·타입 보존 수심에서 해석 가능한 원문 시각의 유일 최빈 양의 간격과 일정 위상으로 만든 **전체 달력 월**의 참고 분모다. 정확히 같은 시각은 한 번만 센다. 첫·마지막 보유 시각으로 분모를 줄이거나 불규칙 시각을 반올림하지 않는다. 간격·위상이 모호한 채널, offset 표현이 섞인 채널은 NULL과 제외 사유를 보존한다. 따라서 참고 격자율은 승인된 예정 관측건수를 사용하는 실제 수집률과 다르다.

결측 표현은 NULL 또는 trim 후 빈 문자열이다. 숫자 sentinel을 임의 결측으로 바꾸지 않는다. 수치 표현은 finite 숫자 해석 가능 여부이며 정상값 판정이 아니다. 원천 QC의 NULL·공백·후행 공백을 보존한다. QC 컬럼이 없는 GR의 기존 카탈로그 `0` placeholder는 실제 schema 부재를 확인한 경우에만 NULL/ABSENT로 보완한다. QC 컬럼이 존재하는 원천의 실제 0건은 엄격히 대조한다.

`GD_OBS_ST_MONTHLY`와 `GD_OBS_VBU`는 모든 보유 월의 실제 파일 schema에서 수신시각 필드 부재를 확인했다. ‘수신시각 필드 없음’은 미산정 숫자나 지연 0초가 아니다. `REGISTER_TIME`·`UPDATE_TIME`을 수신시각으로 대체하지 않는다. 부재 검증은 schema·SHA·footer·동결 카탈로그를 사용하며 원문 수신시각 전수 해석으로 표시하지 않는다.

`GD_OBS_BU`와 `GR_OBS_ST`의 `RECEIVE_TIME`은 원문 관측시각과 직접 산술 비교한다. NULL·해석 불가·음수 차이를 보존하고 비교 가능한 시계 표현의 쌍만 집계한다. 평균·P50·P95는 전체 비교 가능 행의 분포로 계산하며 관측소별 백분위수를 다시 평균하지 않는다. naive 원문에 시간대를 임의 부여하거나 offset 유무가 다른 쌍을 임의 환산하지 않는다. 이 값은 **원문 두 시계의 차이**이며 실제 통신 지연·정상·중단 판정은 아니다.

BU·GR는 각각 33개 보유 월 전체를 실제 원문 시각에서 계산했다. GDST 43개 월·VBU 33개 월의 schema 부재 기록과 과거 정산 13개 월을 합해 155개 월별 수신시각 진단 패킷을 보존한다. 이전 release-v3의 91개 포인터·패킷은 바이트 그대로 유지한다.

| 7월 원천 | 비교 가능 행 | 원문 시계차 평균 | P95 |
|---|---:|---:|---:|
| `GD_OBS_BU` | 3,205,316 | 205.732초 | 315초 |
| `GR_OBS_ST` | 25,268,257 | 29.076초 | 210초 |

시계차가 매 관측마다 달라지는 큰 월은 분포를 무손실 등차 구간과 빈도로 저장한다. 원문 시각·물리 행 locator의 집계는 grain·시계 유형별로 한 번만 하고, 개별 시계차 집계에는 정수 빈도를 사용한다. 정렬된 집계를 작은 묶음으로 읽고 원천이 아닌 별도 작업 디렉터리에 임시 정렬 파일을 둔다. 메모리 부족 시 관측소·exact grain으로 나누고 출력 전 실패한 구간만 다시 계산한다. 구간의 정수 누적 빈도로 전체 행의 정확한 순위와 보간 백분위수를 계산하며, 안전한 int64 범위의 큰 분포는 NumPy로 같은 정수 계산을 수행한다. 기존 작은 빈도표와 패킷은 보존한다. 근사 bin·시각 반올림·백분위 평균은 사용하지 않는다.

정산된 과거 원천의 2013-01 실제 관측소 코드는 `78`이며 4,314행의 수신시각은 NULL이다. `station_id_candidate=DT_0001`을 물리 관측소 연결 승인으로 해석하지 않는다. 과거 전체 2011~2021 자료가 정산되었다는 주장도 하지 않는다.

## 조회 계약

`GET /api/lake/metric-completion`은 원천·기간·관측소·항목·관측망·해역을 그대로 적용한다. `AVAILABLE`, `PARTIAL_CATALOG_COUNTS`, `EMPTY_SCOPE`를 구분하고 `calculation_coverage`에 재검사 월·미완료 월·격자 포함/제외 범위를 반환한다. 범위 전환 시 이전 숫자를 비우며 응답 snapshot이 관측 집계와 다르면 표시하지 않는다. 원천 SHA·파일 membership·catalog·집계 분모가 달라지면 조회를 차단한다.

7월 보고서의 인쇄값은 동일 snapshot의 7월 exact grain에만 연결한다. 다른 월이나 원천의 정상자료율로 재사용하지 않는다. 원천 QC 코드 표기율을 승인 정상/BAD 비율로 바꾸지 않는다.

`GET /api/lake/series?tail=true`는 동일 원천·관측소·항목·월·수심의 해석 가능한 원문 관측시각을 내림차순으로 조회한다. 기본 오름차순 paging은 유지한다. 최근 값의 offset을 전체 카탈로그 행 수에서 추정하지 않으며 다른 수심·관측소·월을 포함하지 않는다. 응답 snapshot과 요청 범위가 일치해야 미리보기에 표시한다.

## 구현과 검증 근거

구현은 [월별 원천 계산](../ocean-ai-platform/backend/app/services/native_month_metrics.py), [월별 계산 CLI](../ocean-ai-platform/backend/app/scripts/recalculate_native_metrics.py), [수신시각 진단](../ocean-ai-platform/backend/app/services/native_receipt_diagnostics.py), [집계 서비스](../ocean-ai-platform/backend/app/services/metric_completion.py), [관측현황](../ocean-ai-platform/frontend/src/pages/Observations.tsx)을 따른다. 최신 검증 수와 영수증 SHA는 [기계 판독 요약](31_OBSERVATION_METRIC_RECALCULATION.json)과 [current_status.json](current_status.json)에 기록한다.

최종 백엔드 회귀는 **776 passed / 1 skipped**, 프런트엔드 로직은 **29 passed**, production build는 통과했다. 독립 에이전트는 142개 월별 패킷의 카탈로그·산식 정산 932,050개 assertion과 실제 GR reader 136개 검사를 통과했다. 부모는 별도 Arrow·Python·NumPy 계산으로 수신시계 3개 실제 채널을 대조하고, 최근 원천값 24건의 시각·값·QC·파일 행 위치를 실제 HTTP와 전수 대조했다. 브라우저 9개 검사는 큰 지도, 해역 범위 축소, 지도·선택 메뉴·목록 동기화, 실제 휠 확대·축소, 원천 항목 전환, 기간 적용과 자료 공백 표시를 확인했다. 이 검증 수를 실제 운영 승인 수로 해석하지 않는다.

실원천·상세 패킷·검증 로그·화면 증거는 `D:/AI_Observation/outputs/observation-metric-recalculation-20261009` 및 `D:/AI_Observation/outputs/monthly-report-matching/native-metrics`에 보존한다. 운영 DB와 계정·승인 기록은 조회만 한다. 단위/배율/기준면·시간대·QC 판본/시행기간·물리 센서 유효기간의 담당 근거와 실제 운영 승인은 이 원문 재계산으로 생성되지 않는다.
