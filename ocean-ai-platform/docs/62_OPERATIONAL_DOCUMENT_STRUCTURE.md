# 운영문서 구조화 v1

2026-10-04. 제한 범위: 개편 QC 가이드북(표지 2023.12.), 인천 이력집 2023/2024 두 종. 전체 운영문서 inventory의 구조화 완료가 아니다.

## 실행 결과

- 원본 문서 3개 SHA256 재검증.
- 관측소·사건 유형·사건 날짜/정밀도·장비 표현·문서 해시·PDF 페이지를 갖춘 기술 사건 16건.
- 사건 요약 16개와 가이드북 기술 기준 페이지 10개: 검색 입력 조각 26개.
- 기압·염분·수온 QC 후보 1,644개 구간에 근거 연결 상태 기록. 선별된 사건의 날짜 중첩 0건, 확정 원인 연결 0건, 라벨 0건.

## 구조 및 판정 원칙

`documents.json`: 문서 출처·해시·판본·업무 분류. 보고서 기준연도를 사건 발생연도나 적용기간으로 대체하지 않는다.

`events.json`: 기술 사건과 원문 발췌, 원문 위치. 날짜 위치 확인은 요약의 사실 검토 완료를 뜻하지 않으므로 PENDING이다. 유효 시작/종료 시각과 물리 센서 연결은 미확정으로 유지한다. 기존 시간축의 관측 데이터 기간 표시 2건은 운영문서 사건에서 제외했다.

`retrieval-chunks.json`: 요약과 원문을 text_kind로 구분한다. 사건 검색 입력은 개인정보를 제외한 기술 요약이다. 가이드북 표 텍스트는 PDF_PAGE_TEXT_TABLE_LAYOUT_REVIEW_REQUIRED로 표시한다. 기존 기준과 개선안을 구분하고 역사적 운영 적용으로 간주하지 않는다.

`qc-evidence-links.json`: 원천 ID·항목·레코드 구간·시각·근거 검토 상태. 날짜 중첩이 있어도 항목·센서·적용 기간 검증 전 확정 연결하지 않는다. 현재 날짜 중첩 없음은 실제 점검이 없었다는 의미가 아니라 **이번 선별 문서 사건에서 연결 근거를 찾지 못했다**는 뜻이다.

## 추출 및 검증 한계

이력집 직접 pypdf 재추출에서 PDF 객체 경고가 발생해 원본 해시가 일치하는 기존 페이지 추출본을 사용했다. 가이드북은 원본에서 페이지 텍스트를 추출했다. 원문 발췌의 날짜 위치 16건을 확인했으나 표 열 배치 및 기술 사건 의미의 담당 검토는 남아 있다. 해시·조각 ID 중복·문서/페이지 참조·미승인 라벨 방지 조건을 검증했다.
