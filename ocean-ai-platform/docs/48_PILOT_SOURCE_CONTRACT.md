# 인천 조위·기압·풍속 좁은 범위 검증 및 F06/F07

조사일: 2026-10-01. **F06의 wide CSV 원천 파서를 구현하고 실제 원천을 전수 읽어 정산했다. F07 표준 Parquet 변환은 근거 미충족으로 실행하지 않았다.** 표준화 초안 전체가 확정됐다는 의미가 아니다.

## 검증 범위와 실제 정산

원천: E:/백업/data/old/spool(2001_2021)/01_raw/2000년자료/1/DT_0001-20000101-20001231-인천.csv

- 전체 크기: 10,894,018바이트. SHA-256: `18faceb185d07ca18b49bf3013e7c3dddebaa81bdee50c7de3005063bb8cb2d6`.
- 전체 파일 57,580개 데이터 행을 파싱했고 전후 해시 일치를 확인했다. 실제 시각 범위는 2000-01-01 00:00:00~2000-12-31 23:56:00이다. 시간대는 원문 시계 기준이다.
- 선택한 하루: DT_0001, 2000-01-01 00:00:00 이상~2000-01-02 00:00:00 미만.
- **원천 57,580 = 형식 격리 0 + 선택 범위 144 + 범위 밖 명시 제외 57,436**. 범위 밖 행을 원본에서 삭제하지 않았다.
- 하루의 144개 행 모두 같은 원천 ID·시각에 OTT/APR/ASP 값이 있으며, 선택 항목으로 펼치면 **144 × 3 = 432개 항목 레코드**다. 같은 관측소·시각 여부는 입증했지만 다변량 Dataset을 만들지는 않았다.
- 전체 파일의 관측소·시각 중복은 0개다. 다른 파일/처리단계와의 전역 중복 제거는 미수행이다.
- 하루 QC 원문: OTT=OK/G 144개, APR=SR/G 144개, ASP=OK/G 144개. QC1과 QC2를 분리해 보존했다. SR/G를 단일 정상 또는 이상 값으로 덮어쓰지 않았다.

현재 Oracle의 기압계 번호 2810, 풍속계 번호 2740에는 설치·종료일이 없다. 이력집의 2021년 설치 장비는 기압계 PTB210/D3950007, 풍향풍속계 05106/126574이다. 이 차이는 원천 메타데이터의 시기 차이를 보여주며 임의로 같은 센서로 합치지 않았다.

이력집 PDF 7쪽의 OTT 설치 표와 16쪽의 2021-03-24 OTT 철거/DOTT 변경 기록도 채널 구분을 요구한다. 후대 장비표를 2000년 OTT 기록에 소급하지 않았다. PDF 장비 표와 과거 유지관리 페이지를 렌더링하여 실제 표 내용을 확인했다.

품질관리 가이드북은 44쪽에서 KST 측정 단위를, 45쪽의 메타데이터안에서는 UTC 시간기준을 표시한다. 67쪽 KST 운영 기준이 있더라도 이번 CSV가 원시 시각인지 변환된 제공 시각인지 연결 근거가 필요하다. ADCP 장비의 KST 설정 설명은 이 조위 CSV에 적용되는 직접 증거로 사용하지 않았다.

2023년 월별 spool CSV도 대안으로 조사했다. 파일 앞부분에 DT_0001의 동시 관측이 보이고 2021년 이후 센서 이력과 연결할 여지가 있지만, 해당 2.3GB 파일의 전수 해시/파싱과 원천 역할 검증을 끝내지 않았으므로 이번 승인 범위에 포함하지 않았다.

## 구현 및 검증

기준 프로젝트에 새 파일로 F06 `pilot_source_parser.py`, 회귀 검증 `test_pilot_source_parser.py`, 이 문서를 반영한다. 적용 범위는 ID/Time 및 OTT/APR/ASP와 각 QC1/QC2 컬럼을 가진 wide CSV다. SQL*Plus/PRD/DAT 전체 파서를 구현한 상태는 아니다.

파서는 원문 시각과 원래 값·결측 표식·QC를 보존한다. 관측소 불일치, 열수 불일치, 중복 헤더, 잘못된 날짜, 무한대 값은 거부한다. 미확인 QC는 원문으로 남기고 UTC·단위·센서 식별자를 임의 생성하지 않는다. 값 변환이나 결측 보간은 하지 않는다.

9개 회귀 검증이 통과했다. 원천 해시 변경 및 필수 근거 없는 공개 계약이 차단되는 경우도 포함한다. 이는 의미 검증 통과가 아니라 파서와 차단 동작 검증이다.

F07 진입 검사도 실제 파일 해시로 실행해 **BLOCKED_BEFORE_PARQUET_WRITE**를 확인했다. 정규화 Parquet 및 다변량 Dataset 생성 건수는 0이다. 아직 Parquet writer, Parquet 재실행 동일성 검증, F07 변환 후 정산을 완료하지 않았다. 위 행수 정산은 F06 원천 파싱 정산이다. 운영 API와 기존 학습 경로에 이 차단 기능이 통합된 상태도 아니다.

## 다음 실행을 여는 필수 근거

1. 이번 CSV의 생성 프로그램/추출 설정과 시간기준, 항목 약어·단위·QC1/QC2 대응표.
2. 2000-01-01 인천 OTT·기압·풍속 센서의 모델/일련번호와 적용 기간 또는 해당 기간 장비를 확정하는 이력 자료.
3. 조위 원시값에 적용된 기준면 및 보정 규칙. 수측기점 높이 자체와 관측값의 기준은 구분해야 한다.

이미 찾은 이력집과 가이드북은 근거로 등록했으며, 위 연결이 확보된 범위만 계약 상태를 VERIFIED로 변경한다. 이 조건을 통과하면 F07의 격리 출력 경로 변환·원천=정상+격리+제외 정산·반복 실행 검증을 수행한다.

## 사용자 지정 MDC 원천 추가 조사 및 F06 반영

사용자가 지정한 품질관리 가이드북을 QC 기준 문서로 연결했다. 알고리즘 코드 설명은 [QC 참조 계약](qc-reference-contract.json)에 전체 파일 해시와 페이지 번호를 기록했다. 해당 가이드북을 참조하는 것과 역사 CSV의 QC1/QC2 필드 의미를 확정하는 것은 구분한다.

- `DT`는 `OCEAN_WEB.DT → RTDB.DT` 동의어였다.
- `T_WM_TW_BUOY`는 현재 계정에서 ORA-00942로 조회되지 않았다. 유사한 이름의 `OCEAN_WEB.T_WRN_TW_BUOY → WRN.T_WRN_TW_BUOY`는 정상 조회됐다. 별개 이름을 같은 객체로 확정하지 않았다.
- 부이 테이블에는 AIR_PRES/WIND_S/관측시각/장비 ID 등이 있으나 조위 컬럼이 없어 조위·기압·풍속 세 항목의 동일 관측소 원천으로 사용하지 않았다. 이름 INCH만 보고 인천 조위관측소와 합치지 않는다.

`WEB_STATION(DATA_TYPE=DT, OLD_ID=78)`로 DT_0001 매핑을 확인했다. 실제 DB 뷰 `VW_WEB_OBS_DT`의 정의를 읽어 다음 대응을 확인했다.

| 원천 컬럼 | 관측 항목 |
|---|---|
| DT_TIDE1 | TIDE_LEVEL_OTT |
| DT_APRESS | AIR_PRES |
| DT_WSPEED | WIND_SPEED |

따라서 일반 `DT_TIDE` 값을 OTT로 임의 선택하지 않고 `DT_TIDE1`을 읽는다. DT의 QC 필드가 없는 상태를 NOT_PROVIDED로 보존한다.

**2013-01-01 DT_TS_ID=78의 1,438행을 읽어 4,314개 항목 레코드로 파싱 검증했다.** 시각 범위는 원천 기준 00:00:56~23:59:57이고, 세 항목 모두 1,438행에 값이 있다. 1,500행 상한에 도달하지 않았으며 중복 관측시각은 없다. 2000년 CSV와 결합하지 않았다.

전체 기간 집계는 30초 제한을 초과하여 중단했으며, 이후 관측소+하루 조건과 복합 인덱스를 확인해 좁혀 읽었다. 전체 DT 건수를 추정치로 확정하지 않았다.

RTDB.DT_STATION과 DT_STATION_BACKUP_20140929의 DT_TS_ID=78 장비 설정은 모두 0행이었다. DT의 IS_SIMULATED는 이번 1,438행에서 전부 NULL이다. 이를 시뮬레이션이라는 판정이나 실제 관측이라는 증거로 사용하지 않았다. WEB_STATION에서 관측소 대응은 확인했지만 물리 센서 이력과 자료 생성 이력은 추가 확인이 필요하다.

F06 파서에 이 DB 대응을 추가하고 **13개 회귀 검증**을 통과했다. 코드·테스트는 기준 프로젝트에 반영했다. F07 표준 Parquet와 다변량 Dataset은 여전히 생성하지 않았다. 파서 원문 검증 결과는 [DT 원천 검증](mdc-dt-parser-validation.json), 쿼리·뷰 정의·매핑 근거는 [DT 조사 증거](mdc-dt-scope-evidence.json), 동의어·컬럼과 오류 기록은 [지정 원천 조사](mdc-named-source-evidence.json)에 있다.
