# 모니터링 UI와 실제 자료 연결

2026-10-07 KST. 사용자가 제공한 대시보드·관측현황·QC·AI 인사이트·장비 운영관리
샘플의 카드/지도/표/상세 구성을 반영했다. 예시 수치·개인명·모델명·신뢰도는 옮기지 않았다.

## 메뉴와 자료

| 주소 | 화면 | 실제 연결 |
|---|---|---|
| `/` | 종합 대시보드 | 완료된 Parquet 검증본 요약, 관측소 지도·표, 보고서 등록부, 일일 문서 색인, 비정형 처리 현황 |
| `/observations` | 관측 현황 | 같은 원천·기간의 관측소/월별 보유량, 지도·표 선택 → 상세 패널 → 실제 Parquet 값/계보 조회 |
| `/qc` | 품질 현황 | 원천 QC 표기 분포, 월별 표기/값 결측률, 관측소×항목 행렬, 연결 조건, 문서 사건 근거 |
| `/ai-insights` | AI 분석 인사이트 | 보유 추이, 문서 사건 지도·검토 목록·원문 인용 위치, 예측·신뢰도·설명 점수의 평가 준비 상태 |
| `/equipment` | 장비 & 운영 관리 | 관리대장 설치 주장, 유지보수 문서 사건, 점검 보고 행, 날짜/일련번호 후보, 충돌 근거 |

다섯 메뉴 사이에서는 `source/from/to`를 유지한다. 관측소·항목 선택은 업무 화면별
필터로 유지하며 다른 메뉴에 적용된 것처럼 표시하지 않는다. 루트의 index route는
`Dashboard`이고 AI 인사이트는 `/ai-insights`이다.

지도는 공통 `OSMBaseLayer`의 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`를 사용한다.
OSM contributors 저작권 링크를 표시하고 타일 오류 시 별도 안내를 표시한다.
관측소 좌표는 기존 PostgreSQL 코드가 정확히 한 건 대응할 때만 참조한다.
좌표 부재를 관측소 부재로 바꾸지 않는다. OSM 배경과 실측/장비 데이터는 별개다.

## 집계 계약

- `/api/lake/monitoring`: source, from_month, to_month, 선택 station/item.
  선택 기간의 보유 행·원천 QC 표기·결측 값·연결 조건·월별 및 채널별 집계.
  QC 표기율 = QC 필드가 있는 행 / 보유 행. 정상률·BAD 비율이 아니다.
  결측 값 0은 미수집 기간이나 관측 공백이 없다는 의미가 아니다.
- 월별 그래프는 미등록 월을 NULL로 표시하며 선으로 연결하지 않는다.
  집계값 중 일부가 NULL이면 해당 전체 합/비율을 확정하지 않는다.
- `/api/lake/daily-reports`: 활성 embedding_version에 게시된 일일 상황/점검 문서를
  document_id 기준으로 센다. 청크 수가 보고서 수가 아니다. 최신 보유 보고일을 기본 선택하며,
  기준일 선택과 원문 발췌/쪽/위치를 제공한다. 전체 색인 기준이고 관측 원천 필터와 별도이다.
  추출된 문서 날짜는 사건 발생일·제출일·승인일과 다를 수 있다.
  제출 대상/기한이 없어 제출률·미제출·승인 완료를 산정하지 않는다.
- 문서 사건은 검증된 월별 기준자료에서 관측소·항목·월이 정확히 대응하는 것만 표시한다.
  `*` 항목과 불명 관측소를 임의 확장하지 않는다. “기간 대응 해소”는 원인/센서/QC 승인이 아니다.
  사례 상세의 source_flags는 보고서 사건 전체 기간이며 화면 선택 기간과 다를 수 있음을 표시한다.
- `/api/lake/equipment-evidence`: 선택 기간에 해당 원천 자료를 보유한 관측소와 문서 후보를 연결한다.
  설치 주장은 해당 관측소의 전체 이력(기간 밖 포함), 정비는 머리글 후보 월,
  점검은 보고서 날짜로 기간을 제한한다. 날짜 미상은 별도 개수로 남긴다.
  날짜의 정밀도·원문 문자열을 유지하고 valid_from/to를 추정하지 않는다.
  관측소 운영 이력은 선택 장비 일련번호까지 연결된 이력으로 표현하지 않는다.
- 실제 운영 장비 수·점검 예정·센서 교체 예정·유지보수 완료율은 승인 원장이 없어 미확정이다.
  기존 `sensor_metadata`에는 2행이 있으나 검증된 물리 센서 전체로 해석하지 않았다.
  기존 `/equipment/status`의 관측소 수=장비 수/알 수 없는 상태=정상 로직은 새 UI에서 사용하지 않는다.
- 예측선·이상 원인·AI 신뢰도·위험도·설명 점수는 승인 평가 결과 미등록 상태를 표시한다.
  문서 발췌는 AI 생성 설명이 아니다. 자동 승인은 구현하지 않았다.
