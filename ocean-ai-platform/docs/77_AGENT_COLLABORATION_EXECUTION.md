### QC 에이전트에 대한 추가 프롬프트

> 품질관리 가이드북의 판본·개편일을 원문에서 확인하라. 사용자가 최신본을 요구했다고 해서
> 파일을 임의로 '2025 가이드북'이라 명명하지 마라. 항목별 단위, 범위, 고정값/튐값 검사,
> 관측간격, 센서 방식, flag 정의, 결측/대체값, 검토·승인 업무절차를 근거 위치와 함께 정리하라.
> 기압 고정값은 저장 자릿수·분해능·저장주기를, 염분 이상은 단위·교정·전도도·점검 이력을,
> 수온 고정값은 센서 이력과 결측 대체 여부를 먼저 확인하라. 표/본문 단위 불일치와 개선안 채택
> 여부는 규칙 이슈로 유지하라. 검사 미실행 또는 이상 후보 없음은 GOOD/정상 운영이 아니다.

### Label·Dataset 에이전트에 대한 추가 프롬프트

> QC의 이상 후보를 센서 고장 정답으로 복사하지 마라. 관측소·항목·실제 센서·사건·기간·
> 문서 위치가 같은지를 검토하라. 미확정 물리 센서에 임의 ID를 채워 제약을 우회하지 마라.
> 설치일, 자료제공 시작일, 보고일, 사용 유효기간을 별도 의미로 보존하라. 사후 보고서를
> 과거 시점 예측 입력으로 사용하지 않도록 가용시각을 검사하라. 후보와 승인 멤버십은 분리하라.

### MLOps 에이전트에 대한 추가 프롬프트

> 데이터셋 승인, 멤버십·hash·분할 검증, 모델 artifact, 실제 평가와 성능 기준, 승인자,
> 추론 runtime, 감시, 롤백 실행 증거를 각각 확인하라. DB의 PRODUCTION 값만으로 실제
> 운영을 증명하지 마라. 시설 운영평가 점수를 AI 정확도로 표시하지 마라. 실행기가 없으면
> 작업을 접수했다고 반환하지 말고, 배포/롤백 불가 이유를 명확히 반환하라.

## 교차 검증과 완료 조건

모델 담당 추가 지시: MLOps 준비도뿐 아니라 기존 학습 소스·가중치의 인도 여부를 감사하고,
가이드 전체 관측항목을 규칙 품질검사·AI 이상 탐지·예측에 대응시킨다. 기존 조위 LSTM
Autoencoder를 고정 모델로 선정하지 않는다. 후속 보고서의 예측 기반 LSTM과 판본을
구별하고 더 나은 후보를 동일 데이터·시간 분할·오경보·지연·비용으로 비교한다. QC 담당의
항목/규칙 원문 표와 모델 적용표를 교차검증하며, 근거 없는 다변량·센서·공간 연결은 금지한다.

1. QC → Label: 원천 flag/재검사/원인 후보/인간 판단이 합쳐지지 않는지 서로 검토한다.
2. Label → MLOps: 미승인 라벨, 불완전 멤버십, 중복 사건, 미래 정보 누수의 진입 차단을 검증한다.
3. 각 API → UI: 같은 질의 조건에서 결과 수·분모·상태·오류 표시가 일치하는지 대조한다.
4. 통합 검증: DB 행·Parquet 재읽기·manifest hash·활성 SQL 청크/Vector ID·실제 검색 인용을 확인한다.
5. 코드를 만든 에이전트의 자체 시험만으로 완료 판정하지 않는다. 교차 검토의 발견사항·수정·잔여
   항목을 해당 문서에 남긴다. 담당자의 사실/QC/배포 승인을 에이전트가 대신하지 않는다.
