# 센서정보 누락과 시점별 연결 미확정 사항

작성일: 2026-10-04. 전체 수치는 프로젝트에 저장된 MDC 원천 snapshot 기준이다. 파일 수정시각은 2026-10-02이며 DB 조회시각이 파일 안에 없어 당일 실시간 조회로 표현하지 않는다. 분모는 **항목 메타데이터 행 24,153개**이지 물리 센서 대수가 아니다.

## 1. 실제 원천 필드 누락

| 필드 | 누락 행 | 영향 |
|---|---:|---|
| 사용 시작일 USE_START_DATE | 24,153 | 과거 관측에 센서 적용 불가 |
| 사용 종료일 USE_END_DATE | 24,153 | 철거/교체 경계 및 계속 운용 여부 불명 |
| 설치일 INSTALL_DATE | 24,153 | 설치 전후 구간 구분 불가 |
| 모델명 S_MODEL_NM | 22,954 | 장비 사양·범위·응답 특성 확인 제한 |
| 일련번호 S_SERIAL_NO | 23,401 | 물리 장비의 개체 식별 제한 |
| 제조사 MAKER | 23,401 | 모델·번호 namespace 식별 제한 |
| 단위 UNIT | 5,160 | 값 변환·물리 범위 검사 제한 |

TE_CODE는 전 행에 있으나 물리 센서 식별 완료를 뜻하지 않는다. WEB_EQUIP_INFO 936행과 관측소+TE_CODE로 연결하면 항목 1,575행은 장비행 1개에 대응하고 22,578행은 대응 장비행이 없다. 해당 계정·테이블·snapshot 범위의 결과이며 MDC 전체에 장비정보가 없다고 단정하지 않는다.

기존 채널 대장의 physical_sensor_id 24,153개 미해결과 원천 일련번호 23,401개 누락은 다른 수치다. 일련번호가 있는 752행도 유효기간·장비 관계 검토가 끝난 것은 아니다. ## 4. 추가로 필요한 센서정보와 확보 우선순위

1. **과거 설치/교체/철거 대장:** 관측소, 원천 항목, TE_CODE, 모델·일련번호, 정확한 적용 기간, 근거 문서/작업번호. 우선 2000년과 2013년 인천 3항목.
2. **장비·채널 연결표:** TE_CODE와 장비번호·일련번호의 관계, OTT/DOTT/VEGA 등의 원천 컬럼 대응, 중복 운용 시 주/보조 센서 선택 규칙.
3. **교정·설치 조건:** 교정일·성적서·유효기간, 설치고/수심, 조위 기준면, 기압 기준, 풍속 평균시간·관측고도. 미제공과 해당 없음 구분.
4. **원천 시각·자료 역할:** 역사 CSV 추출 SQL/작업 이력, 시간대, 집계·다운샘플링, DT.IS_SIMULATED NULL 업무 정의. 현재 상태값으로 대체 금지.
5. **QC 적용 이력:** QC1/QC2의 코드북·버전·기간, 수동 보정 이력, 항목·관측소별 규칙 임계값 및 시행일.

센서 누락이 해소되기 전에도 원천 보존·구조 검사·후보 탐색은 계속할 수 있다. 실제 표준화 공개, 센서별 정밀 QC 정상 판정, 승인 학습 라벨은 해당 범위의 근거 확인 후 진행한다.
