# 긴 결측 탐지 및 학습 데이터셋 단계

`GET /api/imputation/long-gap/detect`는 관측소·센서·변수별 실제 관측 시각의 중앙 간격을 관측 주기로 추정한다. 주기의 `min_gap_periods`(기본 4배) 이상 벌어진 구간을 긴 결측 후보로 반환하고, 시작·종료 시각·결측 주기 수·후보 모델(GRU-D/BRITS/SAITS)을 기록한다.

이 결과는 학습 데이터셋 생성의 입력으로 사용한다. 각 후보 구간 전후의 정상 구간을 추출하고, 실제 관측값을 마스킹한 검증용 샘플과 원래 결측 구간을 분리한다. DatasetRegistry에는 기간·관측소·변수 범위와 feature/label/preprocessing 버전을 저장하며, 보간 결과는 승인 전 원본을 변경하지 않는다.
