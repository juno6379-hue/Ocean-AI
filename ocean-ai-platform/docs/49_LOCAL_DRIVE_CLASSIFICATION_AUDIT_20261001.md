# 로컬·Google Drive 분류 상태 점검

점검일: 2026-10-01. 이번 점검은 로컬 파일 수와 폴더 구조, Google Drive의 확인된 관련 폴더 구조를 조회했다. 파일 이동·삭제는 수행하지 않았다.

## 판정

로컬 대분류 정리는 확인된다. 그러나 Google Drive와 로컬 전체 자료의 분류·대조가 모두 완료되었다고 판정할 근거는 없다. 폴더 정리, 파일별 내용 분류, 변환, DB 적재, 문서 임베딩은 각각 별도로 검증해야 한다.

## 로컬 실측

기준 경로: `C:\AI_Observation\ocean-ai-platform\분류`

| 분류 | 파일 수 |
|---|---:|
| 정형데이터 | 581 |
| 비정형데이터 | 25,498 |
| 소스코드 | 2,326 |
| 요청자료 | 43,551 |
| 보관 | 1 |
| 합계 | 71,957 |

- 비정형데이터 바로 아래에 업무보고서·간행물 유형별 13개 폴더가 있다. `02.비정형데이터` 중간 폴더는 없다.
- `정형데이터/Down/download_Tide`는 여전히 존재한다. 이 폴더의 존재를 근거로 다운로드 자료가 전부 비정형데이터 아래로 이동되었다고 말할 수 없다. 실제 내용에 따른 분류 적정성은 별도 확인이 필요하다.
- 요청자료는 `04.요청자료/1차`, `2차`, `3차` 구조를 보존한다. 기존 06번 문서는 이 자료를 정형·비정형 혼합 원본으로 설명한다. 현재 파일별 재분류 완료 여부는 검증하지 않았다.
- 프로젝트 루트에 요청 자료 목록 HWPX가 남아 있다. 모든 자료 파일이 `분류` 안에 있다는 의미는 아니다.

## Google Drive 확인 범위

[05.자료 수집](https://drive.google.com/drive/folders/1VZD3a-HQEh8ix3EF898G5iv3wE5pccbO)의 직계 폴더:

- `01.정형데이터`
- `02.비정형데이터`
- `03.소스`

[02.비정형데이터](https://drive.google.com/drive/folders/1lMbnUXmHkNfrrqBrt_EE8i2uHYUHxVnU)는 `2022`, `2025` 하위 폴더를 유지한다. 2025 폴더에는 일일상황보고, 서비스 모니터링, 대조기 모니터링, 주간조위편차경향, 품질처리보고서 및 수집률, 일일점검보고서, 해양정보간행물의 7개 폴더가 있다. 로컬은 업무유형을 비정형데이터 바로 아래에 두므로 경로 구조가 동일하지 않다.

확인한 `05.자료 수집` 직계 목록에는 요청자료·보관 폴더가 없다. Drive 다른 위치에 존재할 가능성은 배제하지 않는다. Drive 전체 하위 파일 수, 체크섬, 로컬 대응 경로는 전수 조사하지 않았으므로 업로드 누락이나 동기화 완료 여부는 미확인이다.

## 남은 검증

1. Drive 파일 ID·전체 경로·크기·가능한 체크섬과 로컬 상대경로·크기·체크섬을 연결한 대조표 생성.
2. 동일 자료의 경로 차이, 누락, 중복, 버전 차이를 구분.
3. 요청자료·DAT·TXT·XLSX 등의 실제 내용 기준으로 시계열, 보고서, 기준정보, 소스를 분류.
4. 파일별 분류 상태와 추출·변환·적재·임베딩 상태를 각각 기록.

이전 46번 Parquet 상태 문서의 수치는 별도 `E:\백업\data\old\spool(2001_2021)` 변환 실행의 manifest 및 산출물 집계다. Google Drive나 이 로컬 분류 폴더 전체의 처리 완료를 의미하지 않는다. 당시 변수 집계가 TIDE뿐이었으므로 모든 관측항목의 변환 검증 완료로 해석해서도 안 된다.
